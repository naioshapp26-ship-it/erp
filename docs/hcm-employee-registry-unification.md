# جرد توحيد إدارة الموظفين (HCM)

تاريخ الفرع: `cursor/hcm-employee-registry-photo-ff83`

## الصفحات بعد التوحيد

| البطاقة في لوحة HCM | الرابط | الدور |
|---|---|---|
| ملفات الموظفين | `/hr/employee-360` | السجل المركزي الموحد (`employees` + صورة PostgreSQL) |
| الموظفون الجدد | `/hr/employee-360?mode=add` | نموذج إضافة موظف للسجل المركزي مع صورة إلزامية |
| التوظيف والاستقطاب | `/hr/new-hires` | مرشحون ومقابلات وقبول (ليس سجل موظفين دائم) |
| مرشحون مقبولون | `/hr/accepted-employees` | مرحلة انتقالية + «تحويل إلى السجل المركزي» |
| تشغيل الموارد البشرية | `/hr/human-resources` | لوحة تشغيل عامة |

## ما أُزيل من الازدواج (بدون حذف سجلات)

- بطاقة «موظف 360» لم تعد في قسم إدارة الموظفين كمدخل منفصل — نفس السجل تحت «ملفات الموظفين».
- `/hr/employees` يعرض الآن نفس صفحة السجل المركزي (`hr-employee-360.html`) بدل واجهة موازية.
- «الموظفون الجدد» لم تعد تضيف إلى `new_hires` كسجل دائم؛ الإضافة المباشرة تذهب لـ `employees`.
- «التوظيف والاستقطاب» يستخدم مسار المرشحين (`new_hires` → `accepted_employees` → تحويل).

## الجداول (بدون حذف)

- `employees` — السجل المركزي
- `hr_employee_profiles` + `hr_employee_photo_assets` — الملف والصورة الدائمة
- `new_hires` — المرشحون
- `accepted_employees` (+ `converted_employee_id`) — مرحلة القبول والربط بعد التحويل

## الصورة الشخصية

- حقل إلزامي عند الإضافة في نموذج السجل المركزي
- رفع JPG/PNG/WebP مع معاينة
- حفظ BYTEA في PostgreSQL عبر `/api/hr/employee-profile/:id/media`
- ظهور في شبكة القائمة وملف التفاصيل؛ تعديل/حذف حسب الصلاحية
