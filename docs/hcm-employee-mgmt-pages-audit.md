# جرد صفحات إدارة الموظفين (HCM) — تدقيق تشغيلي

الفرع: `cursor/hcm-employee-registry-photo-ff83` · PR #236 · بدون دمج حتى الموافقة.

مصدر الاختبار: `scripts/uat-hcm-pages-ops-audit.js` + لقطات `/opt/cursor/artifacts/hcm-audit-*.png`.

## إجابات صريحة

| سؤال | الجواب |
|---|---|
| هل «الموظفون الجدد» مجرد نموذج إضافة داخل ملفات الموظفين؟ | **نعم.** البطاقة تفتح `/hr/employee-360?mode=add` — نفس ملف `hr-employee-360.html` ونفس جدول `employees`. ليست صفحة/جدولًا مستقلًا. |
| هل «التوظيف والاستقطاب» مختلف عن «المرشحين المقبولين»؟ | **نعم.** جداول ووظائف مختلفة: `new_hires` (مرشحون + قبول/رفض) → `accepted_employees` (مرحلة انتقال + تحويل إلى `employees`). |
| هل `/hr/employees` سجل مختلف عن `/hr/employee-360`؟ | **لا.** نفس الصفحة HTML (`hr-employee-360.html`). |
| هل `/hr/recruitment` كان مختلفًا؟ | سابقًا لوحة ops عامة؛ في هذا PR أُعيد توجيهه إلى `new-hires.html` ليتوافق مع بطاقة التوظيف. |

## مسار البيانات (بلا تكرار مقصود)

```
التوظيف (new_hires) --قبول--> مرشحون مقبولون (accepted_employees) --تحويل--> ملفات الموظفين (employees)
                                      ^
الموظفون الجدد / إضافة من السجل  ------------------------------------+
```

## جدول الجرد

| الصفحة | الرابط | مستقلة؟ | الوظيفة | عمليات مُثبتة (PostgreSQL) | حكم | نواقص |
|---|---|---|---|---|---|---|
| ملفات الموظفين | `/hr/employee-360` و`/hr/employees` | السجل المركزي | قائمة + ملف 360 + صورة | إضافة، عرض، تعديل، بحث/تصفية، صورة، طباعة/تصدير في التفاصيل | **PASS** | لا حذف موظف من الواجهة (API موجود) |
| الموظفون الجدد | `/hr/employee-360?mode=add` | واجهة لنفس السجل | فتح نموذج إضافة مع صورة إلزامية | فتح مباشر، رفض الحفظ بلا صورة، الحفظ→employees | **PASS** | يعتمد على صلاحية الإدارة |
| التوظيف والاستقطاب | `/hr/new-hires` (`/hr/recruitment`) | مستقلة (مرشحون) | مرشحون ومقابلات وقبول/رفض | إضافة، تعديل، قبول→مزامنة accepted، إخفاء قبول بعد القرار، بحث/طباعة | **PARTIAL** | وثائق غير محفوظة؛ checklist محلي؛ لا تصدير |
| المرشحون المقبولون | `/hr/accepted-employees` | مستقلة (انتقالية) | تحويل إلى السجل بلا تكرار | تعديل، تحويل+صورة، إعادة تحويل 409، بحث/طباعة | **PARTIAL** | تدقيق الواجهة localStorage؛ لا تصدير؛ إضافة يدوية ممكنة |
| تشغيل الموارد البشرية | `/hr/human-resources` | مستقلة (تشغيل) | تذاكر تشغيل HR وليست سجل أشخاص | إضافة/تعديل/حذف تذكرة في `hr_ops_records` | **PARTIAL** | ليست إدارة موظفين؛ لا بحث/تصدير موظفين |
