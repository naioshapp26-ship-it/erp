# قرار محاسبي مقترح — العربون والدفعات المقدمة (ADVANCE)

**الحالة:** مقترح فقط — **لا تنفيذ** حتى الاعتماد الصريح.  
**المرجع:** B1.d.4 / B1.d.5d · لا سياسة ADVANCE جديدة في الكود الحالي دون موافقة.

## الوضع الحالي (حقائق تشغيلية)

| المسار | السلوك |
|--------|--------|
| خدمة `postPaymentReceipt` | ترفض الدفعات بلا تخصيصات (`ALLOCATIONS_REQUIRED`) |
| المسار القديم `POST /finance/payments` (العلم false) | يسمح بـ `payment_type=ADVANCE` و`allocations=[]` وينشئ قيدًا يدين النقدية ويحمل 1130 دون ربط فاتورة — **فجوة محاسبية** |
| صفحة `deposits-advance-payments.html` | واجهة محلية (localStorage) فقط — ليست ترحيلًا محاسبيًا |
| بوابة التحصيل 5a.3 | تحمي التحصيل المخصص لفاتورة؛ لا تعرّف محاسبة العربون |

## الخيارات المقترحة

### الخيار أ — حساب التزام عميل + تسوية لاحقة (موصى به للتشغيل الكامل)
1. فتح حساب في دليل الحسابات: مثل `2150 — دفعات مقدمة من العملاء` (أو ما يعتمده المراقب المالي).
2. عند استلام عربون بلا فاتورة: Dr نقدية/بنك · Cr 2150.
3. عند إصدار الفاتورة أو التحصيل النهائي: Dr 2150 · Cr 1130 (أو تسوية مقابل مخصصات الفاتورة).
4. واجهة `deposits` تُربط بخدمة ترحيل جديدة — خارج مسار Cr 1130 المباشر.
5. المسار القديم: رفض `allocations=[]` مع `payment_type` الذي يمس الذمم، أو توجيهه صراحة لمسار 2150 بعد العلم.

### الخيار ب — حظر تشغيلي صارم (أسرع للتشغيل الآمن)
1. اعتبار ADVANCE خارج مسار التحصيل المرحّل حتى تجهيز الخيار أ.
2. رفض HTTP لأي دفعة بلا تخصيصات (legacy + service) بـ 422 واضح.
3. إبقاء صفحة العربون `coming_soon` / محلية دون ترحيل.
4. لا إنشاء حساب التزام الآن.

### الخيار ج — الإبقاء المؤقت مع تحذير فقط
غير موصى به للتشغيل الفعلي: يُبقي فجوة Cr 1130 بلا Dr مقابل.

## توصية الفريق التقني للإغلاق الآمن
اعتماد **الخيار ب فورًا عند تفعيل أعلام الخدمة / النشر** (قرار تشغيلي يمنع الضرر)، ثم جدولة **الخيار أ** كمرحلة منتج مستقلة بعد اعتماد دليل الحسابات ورقم الحساب من المالية.

## ما لن يُنفَّذ دون موافقتك
- إنشاء حساب 2150 أو أي حساب التزام.
- تغيير سلوك ADVANCE في المسار القديم أو الخدمة.
- ترحيل/عكس دفعات ADVANCE تاريخية (لا يوجد صفوف ADVANCE مؤكدة في آخر تدقيق؛ أي إصلاح لاحق يحتاج موافقة منفصلة).

## سؤال الاعتماد
اختر: **أ** / **ب** / **ج** — أو عدّل رقم حساب الالتزام ومتى يُرفض المسار القديم.
