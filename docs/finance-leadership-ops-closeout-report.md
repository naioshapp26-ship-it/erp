## 2) جرد الوظائف (ملخص)

### مكتمل وقابل للاستخدام الآن
- مركز القيادة `/finance` + كتالوج 360
- دليل الحسابات، قيود اليومية (ترحيل/عكس عبر الخدمة)
- عملاء، فواتير (إنشاء HTTP قديم يرحّل إصدار)، مدفوعات مخصصة مع بوابة سلامة
- تحصيليّات/أعمار ديون، مصروفات، ميزانيات، أصول ثابتة (سجل أساسي)
- تدفق نقدي (ملخص/حركات/شامل)، خطط أقساط
- حوكمة منشورات مرحّلة (منع تعديل/حذف غير الآمن)
- بوابة التحصيل: REJECT 422 / HUMAN_REVIEW 409

### ضروري للتشغيل — متبقٍ بانتظار موافقة
1. **UNIQUE migrations** على Staging ثم Production (`migrations/pending/...`)
2. **قرار ADVANCE** ثم تنفيذ الخيار المعتمد
3. **تفعيل أعلام** `FINANCE_POST_INVOICE/PAYMENT_VIA_SERVICE` تدريجيًا (اختياري لكن موصى بعد UNIQUE+ADVANCE)
4. **دمج Draft PRs** لسلسلة B1 + closeout

### ناقص / مستقبلي (ليس حاجز تشغيل AR الأساسي)
- POS، مخزون، دورة مشتريات كاملة، عمولات، فاتورة إلكترونية/ZATCA حكومي
- عروض أسعار مبيعات حقيقية، خصومات خادمية
- معظم إعدادات صفحة القيادة (coming_soon)
- Idempotency-Key منطقي للتحصيل (B1.d.5c) — تحسين ضد التكرار المنطقي

### معطّل / ظلّي
- `finance/api/payments.js` مظلّل لـ POST الحي؛ محصّن دفاعًا فقط
- بذور `INV-FIN-*` بلا `journal_entry_id` (مقصودة؛ البوابة ترفض تحصيلها إن لم يوجد قيد مرجع)
